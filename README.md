# Каталог рецептов на React

Учебный проект каталога рецептов, первоначально реализованный на чистом JavaScript и впоследствии перенесённый на React.

Приложение реализовано на **React 18** с использованием **Vite**. Данные загружаются из публичного API DummyJSON с помощью Fetch API.

## Демо

[Открыть каталог рецептов](https://naastyurasova21.github.io/recipe-catalog-react/)

## Стек технологий

- React 18.3.1 — создание пользовательского интерфейса и компонентов.
- React DOM 18.3.1 — отображение компонентов в браузере.
- JavaScript (ES Modules) — логика приложения.
- Vite 6.4.5 — локальный сервер разработки и сборка проекта.
- CSS — адаптивная вёрстка и светлая/тёмная темы.
- DummyJSON API — получение данных о рецептах.
- GitHub Pages — публикация приложения.
- gh-pages 6.3.0 — автоматизация публикации.

## Компоненты React

- `App` — корневой компонент, хранит состояние приложения, управляет загрузкой данных и взаимодействием компонентов.
- `Header` — заголовок каталога и переключение темы.
- `Toolbar` — поиск, фильтрация по кухне, обновление подборки и выбор случайного рецепта.
- `RecipeList` — отображение списка карточек, состояния загрузки, ошибки или пустого результата.
- `RecipeCard` — отображение отдельного рецепта.
- `RecipeModal` — отображение подробной информации о рецепте в модальном окне.

Взаимодействие компонентов осуществляется посредством props и функций обратного вызова.

## Используемые React-хуки

- `useState` — управление состоянием приложения.
- `useEffect` — загрузка данных, задержка поиска, сохранение темы и обработка прокрутки страницы.
- `useRef` — управление модальным окном и идентификаторами запросов.
- `useCallback` — сохранение ссылки на функцию загрузки рецептов между рендерами при неизменных зависимостях.

- Переключение светлой и тёмной темы.
- Сохранение выбранной темы в localStorage.
- Отображение индикатора загрузки.
- Отображение сообщения при отсутствии результатов.

## Работа с API

Данные загружаются с помощью Fetch API. При выполнении запросов проверяется статус HTTP-ответа с использованием `response.ok`.

Поиск и фильтрация выполняются на стороне клиента после получения данных из API.

Используемые ресурсы:

- Документация: https://dummyjson.com/docs/recipes
- Список рецептов: https://dummyjson.com/recipes
- Полный список рецептов: https://dummyjson.com/recipes?limit=0

## Запуск проекта

Для запуска необходимо установить Node.js и npm.

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера разработки:

```bash
npm run dev
```

## Сборка проекта

```bash
npm run build
```

Готовая сборка приложения сохраняется в папке `dist`.

## Публикация на GitHub Pages

```bash
npm run deploy
```

Команда выполняет сборку проекта и публикует содержимое папки `dist` в ветку `gh-pages`.
